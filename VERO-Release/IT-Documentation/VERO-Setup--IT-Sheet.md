## אופן הפעולה (שקיפות לבדיקה)
- לחיצה על האייקון פותחת את **VERO.exe** כאפליקציית Windows עצמאית. **לא** נפתח
  Microsoft Edge / Internet Explorer / Chrome. התצוגה היא Chromium המוטמע של Electron.
- המעטפת (`main.js`) נטענת מקומית בלבד (`file://.../resources/VERO.html`), חוסמת כל
  ניווט/חלון חיצוני, ומסרבת לכל בקשת הרשאה (מצלמה/מיקרופון/מיקום וכו').
- תמיכה בעברית/RTL ובמסך מגע + Stylus (יכולות Chromium מובנות).

## חתימה דיגיטלית (מה נדרש מכם)
כדי שהקובץ ייחתם רשמית נדרשת **תעודת Code Signing (Authenticode)** של הארגון:
OV/EV מרשות אישורים ציבורית (למשל DigiCert/Sectigo), או תעודת PKI פנימית
המותקנת כ-Trusted Root אצל תחנות הקצה. החתימה מתבצעת ב-`signtool`/electron-builder
עם חותמת זמן (timestamp) מרשות מאושרת. **בלי התעודה הקובץ יישאר לא חתום** — יש
להחליט מול אבטחת המידע אם לחתום לפני ההלבנה.

## הערה — חתימות מבצע/מאשר בתוך VERO
חתימות ה-Stylus של המבצעים/מאשרים הן **נתוני בד״ח** ונשמרות מאובטחות כחלק מהבד״ח.
הן אינן קשורות ל-Code Signing של הקובץ ולא הוסרו.
