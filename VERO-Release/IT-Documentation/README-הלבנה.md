# איזה קובץ למסור לבדיקה במערכת ההלבנה

מוגשות **שתי אפשרויות** כדי שמערכת ההלבנה תבדוק את שתיהן ותאשר את המתאימה.
שני הקבצים הם חבילות Windows תקינות ושקופות — **ללא הסוואה וללא שינוי סיומת**.

| אפשרות | הקובץ שמוסרים להלבנה | מתאים ל־ |
|---|---|---|
| **1 — VERO Setup** | `VERO-Release/VERO-Setup/VERO-Setup-1.0.0.exe` | התקנה מסודרת עם אייקון שולחן עבודה ומסיר התקנה |
| **2 — VERO Portable** | `VERO-Release/VERO-Portable/VERO-Portable-1.0.0.exe` | הרצה ישירה ללא התקנה |

## חשוב
- **כל קובץ מלווה בגיליון טכני** באותה תיקייה (`IT-Documentation/…-IT-Sheet.md`) עם
  SHA-256, גודל, Runtime, הרשאות, מה נוצר, היכן נשמרים נתונים, ואישור אין-רשת.
- לפני המסירה יש **לבנות** את קבצי ה-.exe על מכונת Windows (ראו `vero-desktop/BUILD.md`)
  ולמלא את שדות ה-SHA-256/גודל בגיליונות — הם מסומנים כ"נקבע בבנייה".
- מומלץ למסור את **שתי** האפשרויות יחד, ולראות איזו מאושרת.
- אם שתיהן נחסמות, מסרו ל-IT את הגיליונות הטכניים לבחינת **חתימה דיגיטלית** או
  רישום ברשימת היתר (whitelist) של הארגון — ואל תנסו לעקוף את ההלבנה.
