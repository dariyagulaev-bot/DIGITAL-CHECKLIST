# VERO-Release — שתי אפשרויות הפצה רשמיות ל-Windows

שתי אפשרויות להפצת VERO, לבדיקה במערכת ההלבנה הארגונית — כדי לראות איזו מאושרת.
שתיהן חבילות Windows **תקינות ושקופות**, ללא הסוואה וללא שינוי סיומת.

## מבנה התיקייה
```
VERO-Release/
├─ vero-desktop/            # פרויקט הבנייה (Electron) — מקור שקוף ובר-בנייה
│  ├─ main.js               # מעטפת אופליין: טוענת רק את האפליקציה המקומית, חוסמת רשת/ניווט חיצוני
│  ├─ preload.js            # ריק בכוונה (ללא גשר ל-Node/OS)
│  ├─ resources/VERO.html   # אפליקציית VERO המלאה (קובץ יחיד, כל ה-assets מוטמעים)
│  ├─ electron-builder.yml  # מייצר את שתי החבילות (nsis + portable)
│  ├─ package.json          # Electron 28.3.3 (מוטמע; ללא WebView2/Edge/‎.NET/‎VC++)
│  └─ BUILD.md              # הוראות בנייה + חתימה + אימות ליעד
├─ VERO-Setup/             # אפשרות 1 — כאן יונח VERO-Setup-1.0.0.exe
├─ VERO-Portable/          # אפשרות 2 — כאן יונח VERO-Portable-1.0.0.exe
└─ IT-Documentation/       # גיליונות טכניים ל-IT/אבטחת מידע + מדריך "איזה קובץ למסור"
```

## איזה קובץ מוסרים להלבנה
- **אפשרות 1:** `VERO-Setup/VERO-Setup-1.0.0.exe`
- **אפשרות 2:** `VERO-Portable/VERO-Portable-1.0.0.exe`

מומלץ למסור את **שתיהן** יחד עם הגיליונות הטכניים שבתיקיית `IT-Documentation/`
(ראו `IT-Documentation/README-הלבנה.md`).

## שקיפות חשובה — כיצד נבנה ה-exe
לא ניתן לבנות או לבדוק קובץ Windows (.exe) בסביבת הפיתוח (Linux/ענן, ללא Windows).
לכן **לא סופק .exe מזויף או מחופש**. מה שסופק הוא **פרויקט הבנייה המלא והשקוף**
(`vero-desktop/`) שמייצר את שתי החבילות. יש לבנות אותן פעם אחת על **מכונת Windows**
(ראו `vero-desktop/BUILD.md`), ואז למלא SHA-256 + גודל בגיליונות הטכניים.

## מה מובטח בשתי האפשרויות
- עבודה **ללא אינטרנט**; ללא Edge/IE/Chrome; ללא URL חיצוני; ללא localhost; ללא Ports.
- כל קבצי VERO וה-assets מקומית; שמירת נתונים קבועה ב-`%APPDATA%\VERO`.
- עברית ו-RTL; מסך מגע ו-Stylus.
- כל הפונקציות: בד״חים, חתימות, תמונות, משתמשים, הסמכות, מבחנים, סנכרון לתחנה המרכזית.
- יעד: **IX101L2, Windows 10 Pro Build 18362 (1903/19H1)** — נתמך; חובה לאמת על המכשיר.

## חתימה דיגיטלית
התוצרים אינם חתומים כברירת מחדל. נדרשת **תעודת Code Signing (Authenticode) של הארגון**
(OV/EV מ-CA ציבורי או PKI פנימי Trusted). פרטי התהליך ב-`vero-desktop/BUILD.md` ובגיליונות.
אין לייצר חתימה מזויפת ואין לעקוף את ההלבנה.

## חתימות המבצעים/מאשרים בתוך VERO
אלו **נתוני בד״ח** (ציור ב-Stylus), נשמרות מאובטחות כחלק מהבד״ח, ואינן קשורות ל-Code
Signing. לא הוסרו.
