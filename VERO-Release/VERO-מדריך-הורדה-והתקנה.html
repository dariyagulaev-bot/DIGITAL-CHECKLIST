לפני הכול — האם קובץ ההתקנה תקין?

זה הכי חשוב: הקובץ שאני בונה תקין ושלם (בדקתי את המבנה שלו לעומק). הקובץ שנפגם הוא זה שחזר אחרי ההלבנה. לכן, לפני שמתקינים — מוודאים שהקובץ לא השתנה.

✓ מה שבדקתי ואישרתיחבילת VERO המקורית נבנתה בהצלחה, המבנה שלה שלם, וכל הקבצים והתלויות בפנים (כולל אפליקציית VERO המלאה). הקוד לא שונה.
⚠ מה שלא יכולתי לבדוקאני עובד בסביבת Linux בענן, ולכן לא יכול להריץ קובץ Windows בפועל. בדיקת ההרצה האמיתית חייבת להתבצע על מחשב/טאבלט Windows (ראי פרק 5).
✕ אם Windows אומר "הקובץ פגום"כמעט תמיד זה אומר שההלבנה שינתה את הקובץ — וזה שובר אותו. הדרך לדעת: משווים SHA-256 לפני ואחרי (פרק 3 ו-4). אם ה-SHA שונה — הבעיה בהלבנה, לא בתוכנה.
1

איך מורידים את קובצי VERO מכאן

בסביבה הזו (Claude) אין "תיקייה" או כפתור הורדה כללי. בכל פעם שאני שולח קובץ, הוא מופיע ככרטיס קובץ בתוך הצ'אט — והכרטיס עצמו הוא ההורדה.

  1. אתרי את כרטיס הקובץ בצ'אט. הוא מופיע כשורה עם שם הקובץ (למשל VERO-App-1.0.0.zip) ואייקון, בתוך השיחה איתי — בדיוק כמו שצירפתי לך קודם.
  2. לחצי / הקישי על הכרטיס. במחשב (claude.ai בדפדפן) — לחיצה שומרת את הקובץ לתיקיית ההורדות (Downloads). בנייד — הקשה פותחת "שמור / הורד".
  3. בדקי שהקובץ נשמר. פתחי את תיקיית Downloads במחשב וודאי שהקובץ נמצא שם עם השם המלא.
  4. זיהוי קובץ ההתקנה הסופי לפי השם — ראי הטבלה בפרק 2. (לדוגמה VERO-Setup-1.0.0.exe.)
  5. ודאי שהקובץ ירד בשלמותו — השוואת גודל ו-SHA-256 (פרק 3). אם הגודל קטן מהצפוי — ההורדה נקטעה, הורידי שוב.
אין לי צילום של מסך הצ'אט שלך (זה הממשק שלך, לא שלי). אם תרצי שאסמן לך בדיוק איפה ללחוץ — צלמי את המסך שבו מופיע כרטיס הקובץ, שלחי לי, ואוסיף חץ והסבר.

בדיקת תקינות — גודל ו-SHA-256

כדי לחשב SHA-256 של קובץ שאצלך, ב-Windows:

לא תקיןאם התוצאה שונה — הקובץ השתנה (הורדה שנקטעה, או הלבנה ששינתה אותו). ראי פרק 4.
בדיקת הרצה על Windowsלא ביצעתי בדיקת הרצה אמיתית (אני ב-Linux). יש להריץ את הקובץ פעם אחת על Windows לפני הלבנה כדי לאשר שהוא נפתח (פרק 5).
4

העברה דרך מערכת ההלבנה

  1. מה מוסרים להלבנה: קובץ אחד — עדיפות ל-VERO-App-1.0.0.zip (נוטה לעבור שלם), ואם מותר exe אז VERO-Setup-1.0.0.exe.
  2. לפני המסירה — רשמי את ה-SHA-256 של הקובץ (פרק 3).
  3. אחרי ההלבנה — חשבי שוב SHA-256 על הקובץ שחזר, והשווי.
  4. אם ה-SHA זהה — הקובץ עבר בשלמותו. אפשר להתקין (פרק 5).
  5. אם ה-SHA שונה — ההלבנה שינתה את הקובץ וזה מה ששובר אותו ("פגום"). אל תתקיני — ראי התיבה למטה.
אם מופיעה הודעת "הקובץ פגום"הסיבה כמעט תמיד: ההלבנה שינתה בתים בקובץ ההרצה. אין לעקוף את ההלבנה ואין לשנות סיומות. במקום זה — ראי מה למסור ל-IT למטה.
מה להעביר לגורם המחשוב (IT) 1. קובץ .exe הוא אפליקציה, לא מסמך — מערכת שמנקה/בונה-מחדש בתים הורסת אותו. יש להעביר אותו במסלול אישור תוכנה / Whitelisting שמעביר בינאריים ללא שינוי (שומר על ה-SHA), או עם חתימה דיגיטלית של הארגון / חריג מאושר.
2. לנסות את VERO-App-1.0.0.zip — שערי הלבנה רבים מעבירים ZIP בלי לשנות את הקבצים הפנימיים.
3. בכל שלב — לאמת SHA-256 לפני ואחרי, כדי לדעת היכן בדיוק הקובץ משתנה.
5

התקנה בטאבלט (IX101L2 · Windows 10 Pro 18362)

בצעי רק אחרי שווידאת שה-SHA תקין (פרק 3–4). בחרי את אחת משלוש הדרכים — כולן מגיעות לאותה תוצאה.

דרך א׳ — גרסת ההתקנה (Setup)

  1. העבירי את VERO-Setup-1.0.0.exe לטאבלט (אחרי הלבנה), לדוגמה לתיקיית Downloads או לשולחן העבודה.
  2. לחצי פעמיים על הקובץ.
  3. אם קופץ חלון כחול "Windows protected your PC" (SmartScreen, כי הקובץ לא חתום) — לחצי על More info ואז Run anyway.
  4. אם הקובץ "חסום": לחיצה ימנית → Properties → למטה סמני Unblock → Apply → נסי שוב.
  5. עקבי אחרי המתקין (Next / Install). ההתקנה היא per-user — אינה מבקשת סיסמת מנהל.
  6. בסיום נוצר אייקון VERO על שולחן העבודה ובתפריט התחל.
  7. פתחי את VERO מהאייקון.

דרך ב׳ — גרסה ניידת (Portable)

  1. העבירי את VERO-Portable-1.0.0.exe לטאבלט.
  2. לחצי פעמיים — VERO נפתח ישר, בלי התקנה. (אם צריך — SmartScreen/Unblock כמו בדרך א׳, שלבים 3–4.)
  3. אין אייקון קבוע; להפעלה חוזרת פתחי שוב את אותו קובץ. (אפשר ליצור קיצור דרך: לחיצה ימנית על הקובץ → Send to → Desktop.)

דרך ג׳ — מתוך ה-ZIP

  1. לחיצה ימנית על VERO-App-1.0.0.zip → Extract All → בחרי תיקיית יעד → Extract.
  2. היכנסי לתיקייה שנוצרה, אתרי את VERO.exe ולחצי עליו פעמיים. (SmartScreen/Unblock במידת הצורך.)
  3. להפעלה חוזרת — אותו VERO.exe מהתיקייה.

איך בודקים שהיא עובדת (וגם בלי אינטרנט)

  1. אחרי הפתיחה יופיע מסך הכניסה של VERO (ראי תמונה למטה). זה סימן שהיא עובדת.
  2. כבי את ה-Wi-Fi בטאבלט.
  3. סגרי ופתחי את VERO שוב, והתחברי. אם הכול עובד בלי רשת — מצוין, זו בדיוק המטרה.
  4. פתחי בד״ח לדוגמה כדי לוודא שמסך הבית וטפסים נטענים.

אם מופיעה הודעת שגיאה

  • "הקובץ פגום / damaged" → בדקי SHA-256 (פרק 3). אם שונה מהמקור — הבעיה בהלבנה (פרק 4), לא בטאבלט.
  • SmartScreen כחול → More info → Run anyway.
  • אנטי-וירוס מסיר את הקובץ → פני ל-IT לאישור/חריג.
  • לא קורה כלום בלחיצה → ודאי שהקובץ ירד בשלמותו (גודל + SHA), ונסי את גרסת ה-ZIP (דרך ג׳).
אין לי צילומים של: מסך ההלבנה שלכם, מסכי Windows בטאבלט (SmartScreen/Properties/המתקין), והטאבלט עצמו. לא המצאתי אותם בכוונה. אם תרצי מדריך עם צילומים אמיתיים של השלבים האלה — צלמי כל מסך תוך כדי (למשל את חלון SmartScreen ואת המתקין), שלחי לי, ואבנה גרסה מורחבת עם התמונות שלך מסומנות.
6

סיכום קצר — מה לעשות עכשיו

  1. הורידי מכאן את VERO-App-1.0.0.zip (כרטיס הקובץ בצ'אט) ושמרי ב-Downloads.
  2. רשמי/בדקי את ה-SHA-256 שלו (פרק 3).
  3. העבירי אותו להלבנה. אחרי שחזר — בדקי SHA-256 שוב.
  4. אם זהה → התקיני לפי פרק 5 (דרך ג׳). אם שונה → מסרי ל-IT את ההסבר מפרק 4.
  5. בטאבלט — ודאי שהיא נפתחת ועובדת גם בלי Wi-Fi.
