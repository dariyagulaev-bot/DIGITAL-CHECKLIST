Place the VERO application icon here as:  icon.ico

Requirements for electron-builder:
  • Windows .ico file, containing multiple sizes (recommended 16,24,32,48,64,128,256 px).
  • 256x256 must be present.

If icon.ico is missing, electron-builder falls back to the default Electron icon
(the build still succeeds). Supply the organization's VERO icon before the
official build so the installed app and shortcut show the VERO logo.
