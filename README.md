# כיסי

התקציב של הבית, בכיס.

אפליקציה לטלפון לניהול התקציב האישי והביתי: הכנסות, הוצאות קבועות ומשתנות, תכנון חודשי, יעדי חיסכון, היסטוריית חודשים, גרפים וסיכומים.
האפליקציה בעברית, מימין לשמאל, ועובדת גם בלי אינטרנט. הנתונים נשמרים במכשיר.

## התקנה בטלפון

האפליקציה היא PWA: פותחים את הכתובת שלה בדפדפן ומוסיפים למסך הבית. היא נפתחת במסך מלא כמו אפליקציה רגילה.

- **iPhone (Safari):** כפתור השיתוף ← "הוספה למסך הבית".
- **Android (Chrome):** תפריט ⋮ ← "התקנת אפליקציה" / "הוספה למסך הבית".

חשוב: הנתונים שמורים בדפדפן של המכשיר. ב־iPhone כדאי תמיד לפתוח מהאייקון במסך הבית, ומדי פעם ליצור גיבוי (עוד ← גיבוי וייצוא).

## פרסום

ה־workflow ב־`.github/workflows/deploy.yml` בודק ובונה כל push, ומפרסם ל־GitHub Pages כל push ל־`main`.
להפעלה: Settings ← Pages ← Source: **GitHub Actions**. ‏GitHub Pages ממאגר פרטי דורש מנוי GitHub Pro. אפשרות אחרת היא להפוך את המאגר לציבורי: הקוד יהיה גלוי, אבל הנתונים האישיים לעולם לא נשמרים במאגר.
אפשר גם לחבר את המאגר ל־Netlify, ל־Vercel או ל־Cloudflare Pages: פקודת build היא `npm run build` ותיקיית הפלט היא `dist`.

## פיתוח

```bash
npm install
npm run dev        # שרת פיתוח
npm test           # בדיקות לחישובי התקציב ולשכבת הנתונים
npm run build      # בנייה לתיקיית dist
```

מבנה הקוד וההכנה לסנכרון ולמשתמשים מתוארים ב־[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
